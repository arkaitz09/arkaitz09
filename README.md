## Featured project

### Aries

> A web app for a healthcare team that turns appointment Excel files into ready-to-send WhatsApp messages for patients' families.

**Tech:** React · Vite · Cloudflare Pages

**What makes it interesting:**
- Built for a real need and **used by a 3-person healthcare team**
- Excel files are processed **entirely in the browser** — patient data never leaves the user's device
- It started with a Spring Boot backend (JWT in HttpOnly cookies, Cloudflare Worker as reverse proxy). Once it was clear the backend only provided login, I removed it: the hosting cost wasn't justified, and going client-only also removed a whole class of data-handling risks

🔗 **[Live →](https://aries.audicted.es)**
